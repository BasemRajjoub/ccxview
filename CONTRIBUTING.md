# Contributing to ccxview

Bug reports, test models and ideas are very welcome: open an issue at
https://github.com/BasemRajjoub/ccxview/issues.

Code contributions are welcome too. ccxview is owned and licensed by Basem
Rajjoub (see [LICENSE](LICENSE)), so every pull request has to come under the
Contributor Agreement below. Opening a pull request means you agree to it;
the pull request template asks you to confirm it.

Before you start on a large change, please open an issue first so we can agree
on the approach.

## Building and testing

See [docs/build.md](docs/build.md). Please run `make test` and, for changes to
the user interface, `scripts/ui-test.sh` before you open the pull request.
